# Customer Support Analytics Dashboard

## Overview

This project focuses on analyzing customer support operations using Power BI to uncover trends in customer interactions, service quality, and workforce performance. The dashboard provides actionable insights into ticket volumes, customer satisfaction, agent productivity, and support channel effectiveness.


## Objectives

* Analyze customer support ticket trends.
* Measure customer satisfaction (CSAT) performance.
* Identify high-volume support categories.
* Evaluate agent and shift performance.
* Monitor support channel distribution.
* Generate business insights for operational improvement.


## Dataset Information

* Dataset: Customer Support Data
* Records Analyzed: 68,000+
* Domain: Customer Service & Operations
* Tool Used: Power BI

### Key Fields

* Agent Name
* Agent Shift
* Category
* Channel Name
* CSAT Score
* Customer City
* Issue Reported At
* Issue Responded
* Supervisor
* Manager
* Survey Response Date

## Data Preparation

* Removed irrelevant and highly incomplete columns.
* Checked data quality and missing values.
* Validated data types.
* Cleaned and transformed data using Power Query.
* Created calculated measures using DAX.

## KPIs

### Total Tickets

Measures the total number of customer support requests received.

### Average CSAT Score

Tracks overall customer satisfaction performance.

### Total Agents

Shows the number of active support agents.

### Total Supervisors

Monitors supervisory workforce coverage.



## Dashboard Visualizations

### Ticket Distribution by Category

Identifies categories generating the highest support volume.

### Ticket Distribution by Channel

Analyzes customer interaction channels such as Inbound, Outcall, and Email.

### Top Performing Agents

Highlights agents handling the highest ticket volumes.

### Shift-Wise Ticket Analysis

Evaluates workload distribution across Morning, Evening, Afternoon, Split, and Night shifts.

### Average CSAT by Category

Measures customer satisfaction across different issue categories.

### Average CSAT by Shift

Analyzes customer satisfaction trends across work shifts.


## Key Insights

* Processed over 68K customer support tickets.
* Returns category generated the highest number of support requests.
* Inbound channel accounted for approximately 79% of total interactions.
* Average customer satisfaction score remained above 4.2 out of 5.
* Morning and Evening shifts handled the majority of customer requests.
* Agent performance analysis helped identify top contributors and workload distribution patterns.
